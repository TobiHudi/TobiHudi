# Liberio:
A simple shelf sorting game. Sort shelves and get better upgrades.

### Goal of Liberio:

The main goal of this project was to deepen my understanding of object oriented coding and connecting multiple more complex systems together. The project is also rather dynamic, modular and easy to set up. Most Nodes are being instantiated dynamically inside their respective scripts. Another goal was to make everything as signal/event oriented as possible and avoiding heavy logic inside the _process function (gets called every frame). I also learned how to use git and commit projects to a branch through this project. This also really helps documenting the development cycle.

More to the Project can be found inside the repo! (Signal paths, ect...)
